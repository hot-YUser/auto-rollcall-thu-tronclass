# iClass 前端成果

先讀 `REPORT.md`。結構化結果在 `data/`，前端快照在 `raw/`，閱讀用 JS 在 `readable_js/`。

主要索引：

- `data/api_endpoints.csv`：去重 API endpoint。
- `data/routes.csv`：前端路由與頁面路徑。
- `data/browser_surfaces.json`：storage、cookie、iframe、postMessage、eval-like、websocket 等瀏覽器能力使用面。
- `data/technologies.json`：技術依賴證據。
- `data/readable_js.csv`：閱讀用 JS 清單。
